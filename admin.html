数据管理 · 组合类产品行业数据库

每月脚本更新 Excel 后，在此上传即可自动刷新网页数据（仅本机使用）。

① 上传总数据库（每月必须）

② 上传月度产品明细表（可多选，如 2607、2608…）

③ 开始更新

上传后自动运行处理管道（约 10~30 秒），完成后刷新网页即可看到新数据。

④ 同步到公网（Git 版本管理）

把本地最新数据推送到公网固定网址，约 1 分钟后生效；每次部署自动生成一个 Git 版本（commit），可在下方查看历史。
公网网址：https://shiweiwang0096.github.io/product-db/

⑤ 版本历史（GitHub）

每次「一键更新公网」都会在 GitHub 仓库留下一个历史版本（代码+数据备份），可按需回溯。

⑥ Supabase 云端数据库（可选）

配置后，每次更新数据可一键同步到 Supabase 云数据库；网站页面会自动优先从云端读取数据（云端数据库离线时自动回退本地文件）。
首次使用：注册 supabase.com → 新建项目 → SQL Editor 执行建表语句（见 README）→ 填上 Project URL 和 anon key。

使用说明

  1. 每月脚本产出 Excel 后，打开本页（通过网站顶部「数据管理」按钮进入）。
  2. 总数据库：每次上传的都是最新版本，自动覆盖旧的总数据库（只保留最新一份）。
  3. 月度明细表：历史月份永久保留——已传过的月份（见「当前数据状态」列表）不用重复上传，只需上传新增月份；若重复上传同名文件，则自动覆盖该月份旧版本。
  4. 选择文件后点「③ 上传并刷新网页数据」；如需同步给其他人，再点「④ 一键更新公网网址」。
  5. 公网网址（GitHub Pages）不支持上传；上传与部署功能仅在本机（localhost）提供。
